## State of the two research threads

### 1. Abliteration defense (ABL-v7) — STRONG, and now shown to generalize
Full 2x2x3 judge-labeled battery (clean/abliterated x OG/v7 x prefill/HarmBench/
BeaverTails), `docs/findings_prefill_harmbench_beavertails_2026_07_02.md`:
- **Positive:** abliterating ABL-v7 -> 0% ASR / **100% gibberish** across all three
  attacks incl. prefill (a non-gradient attack it was never trained on) and two
  off-distribution prompt sets. Abliterating base OG -> real coherent harm
  (ASR 0.41-0.80). MAD generalizes beyond AdvBench — stronger than prior claim.
- **Caveat (new, must report):** CLEAN ABL-v7 (no attack) has real baseline
  coherence cost off-AdvBench: 13.5% gibberish on prefill, 20% HarmBench, 50%
  BeaverTails (vs ~0% for clean base). The "clean product is free" claim only held
  because original validation was AdvBench-only. Open: does it bleed into ARC/MMLU?
  (the full-suite run now answers this — see commands.)
- Those numbers were n=200 subsets; the full-dataset re-run is what's now queued.
