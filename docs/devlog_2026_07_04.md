# Devlog 2026-07-04 — ABL-v8: the conditional wall (fixing v7's clean tax)

## Motivation: v7 works but its clean product is degraded
ABL-v7 resists abliteration (attack → gibberish + capability crater) but the CLEAN model is
damaged: Qwen v7-clean gibberishes 97% on harmful prompts, IFEval −30%; gemma −62%; llama −89%.
The entanglement is "always on", not conditional on the attack. Root cause (from the trainer):
v7's clean-fidelity anchor is `L_task` = teacher-forced CE — loglikelihood-style, the SAME blind
spot as ARC/MMLU. It misses free-generation drift, so `λ_gib` bled into clean generation.

## v8 fix 1: generative clean anchor
`train_tamper_resistant_v8.py` adds `L_clean_gen = λ_clean·KL(base_gen ‖ clean_gen)` on benign
prompts — pins the CLEAN model's free-generation distribution to the frozen base. Plus an
eval-in-loop 24-prompt instruction probe (scored on the clean model each eval step).

## v8 fix 2: two-stage curriculum (the Pareto is real)
Single-stage λ traces a clean↔wall Pareto with NO both-high point: making the ablated model lose
general generation (the MAD wall, trained on benign continuations) and keeping the clean model's
benign generation (the anchor) are the SAME circuit, opposite targets, gated by a rank-1 direction.
Fix = curriculum: STAGE 1 form the wall (λ_clean 0), STAGE 2 ramp the clean anchor in to REPAIR
while gib holds. Knobs: `--clean-start-step --clean-ramp-steps --stage2-lambda-gib`.
