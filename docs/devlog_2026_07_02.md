## Thread 2 — FTR-v6: FAILED (lobotomy), confirmed two ways.

FT-resistant via capability collapse is indistinguishable from real resistance without
a capability eval; ASR-alone called it a win. `usefulness_label` + MC-capability caught it.

## Built — FTR-TAR (`experiments/train_ft_resistant_tar.py`)
Faithful TAR (Tamirisa et al. 2408.00761), fixing exactly why v6 died:
- **RETAIN = KL(frozen-reference || current) on benign tokens.** Hard capability anchor
  to the warm-start model (ABL-v7). Lobotomy = large benign-KL = penalized directly.
  This is what v6 lacked (v6's CE-on-corpus doesn't anchor to a base model).
- **Tamper-resistance = BOUNDED** relu(tr_cap − post-attack forget CE). Saturates once
  the attack fails instead of blowing up and dragging capability down (v6's unbounded
  unlikelihood did the latter).
- Inner adversary = LoRA fine-tune (rank 16, realistic cheap attack), FO-MAML meta-grad.
- User asks wired: `--gen-tokens` matches eval judge horizon (512 AdvBench), `--gen-prompts`
  32 held-out (v6 pigeonholed ~10), saves **best (by val_score) + latest** ckpts.
  val_score = post-attack frac_comply + beta*retain_KL.
- Warm-start + retain reference both = ABL-v7 (preserve its capability, add FT-resistance).
