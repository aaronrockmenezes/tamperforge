## Built — FTR-TAR (`experiments/train_ft_resistant_tar.py`)
Faithful TAR (Tamirisa et al. 2408.00761), fixing exactly why v6 died:
- **RETAIN = KL(frozen-reference || current) on benign tokens.** Hard capability anchor
  to the warm-start model (ABL-v7). Lobotomy = large benign-KL = penalized directly.
  This is what v6 lacked (v6's CE-on-corpus doesn't anchor to a base model).
- **Tamper-resistance = BOUNDED** relu(tr_cap − post-attack forget CE). Saturates once
  the attack fails instead of blowing up and dragging capability down (v6's unbounded
  unlikelihood did the latter).
- Inner adversary = LoRA fine-tune (rank 16, realistic cheap attack), FO-MAML meta-grad.
- User asks wired: `--gen-tokens` matches eval judge horizon (512 AdvBench), `--gen-prompts`
  32 held-out (v6 pigeonholed ~10), saves **best (by val_score) + latest** ckpts.
  val_score = post-attack frac_comply + beta*retain_KL.
- Warm-start + retain reference both = ABL-v7 (preserve its capability, add FT-resistance).

# Phase 2 — Multi-model + multi-seed ABL-v7, and the adaptive attack (2026-07-02 pm/eve)

Goal: does ABL-v7 (the gemma abliteration defense) generalize to other architectures
(Llama-3.2-1B, Qwen3-0.6B) and across seeds, and does it survive a *stronger* attack.
On a 4x RTX 3090 box (24GB each). Codex prepped launch scripts; validated + fixed here.

## Results so far (AdvBench 520, LLM-judged)
- **gemma seed42 + seed2: FULL WIN, reproduced.** Ablate v7 -> ~0 ASR / ~100% gibberish
  + capability crater (seed2: ARC 0.338->0.210, MMLU 0.385->0.258; ablate base -> 0.819 harm).
- **Qwen3-0.6B: DEFENDS robustly** across ALL attack layers (judge ASR 0.01-0.07, gib ~0.99
  at layers 7/10/14/18) but capability NOT cratered (selective harmful-gibberish, benign intact).
- **Llama-3.2-1B: FAILED at DL=8 -> but CONFOUNDED.** Layer sweep (judged): base uncensors
  0.60 coherent harm at **layer 13** vs 0.47 at layer 8 -> DL=8 was a bad (mid-depth) guess;
  Llama's refusal lives deep (L13/16). Retrain at DL=13 in progress. Llama safety is also
  more diffuse (base maxes at 0.60 vs gemma 0.82) -> less single-direction-mediated.

## Attack strength — the core limitation found
Our whole battery used **rank-1 single-direction diffmeans** abliteration (the weakest
attack). `svd`/`whitened_svd` estimators are duds (don't uncensor base). So "ABL-v7 is
robust" only meant "robust vs the cheapest attack." Built `save_p1b_checkpoint --per-layer`:
an ADAPTIVE attack that computes an independent diffmeans refusal direction at EACH layer
and ablates each layer with its own -- much stronger, on our working diffmeans (no dud SVD,
no external AGPL code vendored). Running it on OG gemma ABL-v7 + base now. If v7 stays
gibberish under per-layer attack -> genuinely strong; if it uncensors -> rank-1-specific,
motivates ABL-v8 (train against per-layer/adaptive attacks). External adaptive-attacker
tool (AGPL) = run-as-separate-harness + cite; never vendor its source.

## KEY RESULT — ABL-v7 survives a PER-LAYER ADAPTIVE attack (2026-07-02 eve)
The whole battery used rank-1 single-direction abliteration (weakest). Built `--per-layer`
(independent diffmeans refusal direction per layer, ablated from that layer = much stronger,
adaptive; the core of purpose-built adaptive attackers). Ran it on OG gemma ABL-v7 + base:
- **OG gemma v7 under per-layer attack: judge ASR 0.002, harmAct 0.000, gibberish 1.000
  (520/520), ARC 0.34->0.27, MMLU 0.39->0.24.** The stronger attack does NO better than
  rank-1 (~0.006 harmAct / gib): still 100% gibberish + capability crater. The entanglement
  is robust to adaptive abliteration, not just the cheap rank-1. **This is the strongest
  robustness result in the project** — kills the "a smarter attacker routes around it" doubt.
- base per-layer attack (`gpl_base`) = reference (should uncensor coherently) — running.
- Next: same per-layer attack on Qwen-v7 + Llama-L13 (do their leakier walls hold vs the
  stronger attack? gemma held perfectly; Llama-L13 leaked 13% even at rank-1).

## Llama-L13 rescue (the DL bug fixed)
Retraining Llama at its TRUE refusal layer (L13, found by sweep: base uncensors 0.60@L13 vs
0.47@L8) dropped v7_att harmAct 0.654 (L8) -> 0.133 (L13). The apparent "Llama fails to
transfer" was mostly a layer-selection bug (codex's 50%-depth guess). Llama now defends
(74% gibberish) but LEAKS ~13% (diffuse safety: base only uncensors to 0.66 even at best
layer; no capability crater -> Qwen-style wall, not gemma-style). Per-model refusal-layer
selection is essential = a real contribution.
